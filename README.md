# ✈️ NASA Turbofan Predictive Maintenance & RUL Estimation System

An end-to-end, enterprise-grade Predictive Maintenance (PdM) platform for aircraft gas turbine engines based on the **NASA Commercial Modular Aero-Propulsion System Simulation (C-MAPSS)** dataset.

---

## 🏛️ System Architecture

```
[ LOCAL PIPELINE ]
  Telemetry Replay (Python Producer)
           │
           ▼ (Streaming Telemetry via Kafka Topics)
  Apache Kafka (KRaft Single-Node Mode)
           │
           ▼ (Consumer Ingestion)
  PostgreSQL (Time-Series DW)
           │
           ▼ (dbt Models: Rolling Aggregates + Piecewise RUL)
  Feature Store (`data/processed/features_fd001.parquet`)
           │
           ├───────────────────────────────────────────────┐
           ▼                                               ▼
[ CLOUD / GOOGLE COLAB (A100 GPU) ]              [ DAGSHUB MLFLOW ]
  Deep Learning Training                          Centralized Model Registry
  - CNN-BiGRU + Self-Attention                    & Metric Tracking
  - PatchTST / Transformer                        (Loss, RMSE, NASA Score)
  - Conformal Prediction (MAPIE)                           │
           │                                               │
           ▼ (Export ONNX)                                 │
[ LOCAL SERVING & DASHBOARD ] <────────────────────────────┘
  FastAPI (Low-latency CPU Inference via ONNX Runtime)
  Streamlit (Fleet Overview, Sensor XAI, Cost-Benefit Decision Intelligence)
```

---

## 🛠️ Tech Stack

- **Streaming & Messaging:** Apache Kafka (KRaft mode via Docker, zero-ZooKeeper)
- **Data Validation & Schemas:** Pydantic V2
- **Data Warehouse:** PostgreSQL 16
- **Data Transformation & Tests:** dbt (data build tool)
- **Machine Learning & Deep Learning:** PyTorch, LightGBM, Optuna, Scikit-learn
- **Time-Series & Uncertainty:** 1D-CNN + BiGRU with Temporal Attention / PatchTST, MAPIE (Conformal Prediction)
- **Experiment Tracking:** DagsHub + MLflow
- **Serving:** FastAPI, Uvicorn, ONNX Runtime
- **Dashboard & UI:** Streamlit, Plotly
- **Quality Assurance & CI:** Pytest, Ruff, GitHub Actions

## 🚀 Getting Started

### 1. Prerequisites
- Docker & Docker Compose
- Python 3.10+
- Git

### 2. Environment Setup
```bash
# Clone the repository and navigate into it
cd "NASA TurboFan"

# Copy environment variables
cp .env.example .env

# Create and activate virtual environment
python -m venv venv
venv\Scripts\activate   # Windows
# source venv/bin/activate # Linux/macOS

# Install dependencies
pip install -r requirements.txt
```

### 3. Spin up Infrastructure
```bash
docker compose -f docker/docker-compose.yml up -d
```
- **PostgreSQL:** `localhost:5432`
- **Apache Kafka:** `localhost:9092`
- **Kafka-UI:** `http://localhost:8080`
